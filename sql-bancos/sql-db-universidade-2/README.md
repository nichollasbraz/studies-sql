## Exercício 1

> `Consulta 1`

*Crie um curso “CS-001” intitulado “Weekly Seminar”, com zero créditos.*

> `Consulta 2`

*Crie uma seção desse curso no outono de 2017, com id_sec de 1 e com o local desta seção ainda não especificado.*

> `Consulta 3`

*Matricule cada aluno do departamento Comp. Sci. na seção do item 2.*

> `Consulta 4`

*Exclua as matrículas na seção do item (3) onde a ID do aluno é 12345.*
